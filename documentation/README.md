# Documentation

This directory contains detailed documentation for the Enterprise Dual-WAN OSPF Network Lab.

## Contents

### Network Architecture
Description of the HQ, branch offices, WAN-1, and WAN-2 design.

### IP Addressing
Complete IP addressing plan for LAN and WAN networks.

### VLAN Design
VLAN assignments and Layer 2 segmentation.

### OSPF Design
OSPF Area 0 configuration, router IDs, neighbors, and route advertisement.

### Traffic Flow
Examples showing how packets travel between different sites.

### WAN Redundancy
Explanation of the dual-WAN architecture and future failover testing.

### Troubleshooting
Common troubleshooting commands and procedures used during the lab.

### Verification
Commands and tests used to verify connectivity and routing.
